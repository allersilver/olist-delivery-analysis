# Olist 배송 지연 분석 및 일별 주문량 예측

Olist 브라질 이커머스 공개 데이터로 진행한 두 가지 분석

1. 배송 지연이 리뷰 점수, 재구매율에 미치는 영향
2. 일별 주문량 예측과 예측 오차 분석

- 데이터: [Olist Brazilian E-Commerce Public Dataset (Kaggle)](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
- 도구: SQLite, Python(pandas, scipy, scikit-learn), Tableau

---

## 1. 배송 지연 영향 분석
2026.07 ~ 2026.08

### 결과
| 가설 | 결과 |
|---|---|
| 배송 지연 → 리뷰 점수 | 4.29점 → 2.56점, Cramér's V 0.386 (강한 영향) |
| 배송 지연 → 재구매율 | 3.03% → 2.49%, Cramér's V 0.009 (유의하지만 효과 미미) |
| 발송 소요시간 → 지연 | 상관계수 0.23 (약함) |
| 운송 소요시간 → 지연 | 상관계수 0.55 (지연의 주요 원인) |
| 판매자-고객 거리 → 지연 | 상관계수 -0.09, 거리에 비례해 예상 배송일을 넉넉하게 잡아서 상쇄된 것으로 확인 |

- 고객은 배송 지연에 리뷰로는 크게 반응하지만 재구매로는 크게 반응하지 않음
- 지연 원인은 판매자 발송보다 택배사 운송 구간에 있음
- 재구매 방어보다 운송 파트너 관리, 지연 고객 리뷰 대응을 우선하는 것으로 판단

### 분석 과정
- 도착일이 2017-09-19 하루에 몰린 주문 282건을 데이터 오류로 판단해 제외
- 주문당 최대 3건까지 중복된 리뷰는 최신 1건만 사용
- 재구매율이 처음엔 지연 고객에서 더 높게 나옴. 한 번이라도 지연을 겪은 고객을 모두 지연 그룹으로 분류해서 주문이 많은 고객이 몰린 것이 원인. 고객별 첫 주문 기준으로 다시 분류해 재검증
- 거리와 지연이 반대로 나온 결과는 예상 배송일과의 관계를 추가로 확인해 원인 확인

## 2. 일별 주문량 예측
2026.10

### 결과
| 방법 | MAE | MAPE |
|---|---|---|
| 회귀 모델 2 (추세 변화 반영) | 49.6 | 28.4% |
| 베이스라인 A (지난주 같은 요일) | 51.4 | 24.4% |
| 베이스라인 B (최근 4주 같은 요일 평균) | 52.4 | 24.4% |
| 회귀 모델 1 (추세 직선) | 61.2 | 36.4% |

- 학습 538일, 테스트 56일(2018-06-27 ~ 08-21)
- 회귀 모델 1은 2017년 성장 속도가 2018년에도 이어진다고 계산해 매일 70 ~ 110건 높게 예측
- 2018년부터 증가 속도를 따로 반영하는 피처를 추가해 MAE 61.2 → 49.6 (약 19% 감소)
- 건수 기준으로는 회귀 모델 2, 비율 기준으로는 베이스라인이 더 정확. 회귀 모델은 미리 알 수 있는 요인(요일, 공휴일, 이벤트)에, 베이스라인은 갑작스러운 변화를 따라가는 데 강점

### 분석 과정
- 분석 기간 2017-01-05 ~ 2018-08-21 (594일). 앞뒤는 데이터 수집이 불안정한 구간이라 제외 (전체의 1.06%)
- 요일 패턴: 월요일 최다, 토요일 최소, 주말이 평일보다 약 25% 적음
- 성장: 전년 동기 대비 2.06배
- 주문 감소 구간 3곳 확인
  - 연말연시: 크리스마스, 새해 당일에 급감 후 바로 회복
  - 2018년 5월: 브라질 트럭 운전사 파업 기간과 겹침 (-47.5%)
  - 2018년 7월: 원인 미확인 (-28.1%)
- 블랙프라이데이, 파업, 브라질 공휴일을 피처로 반영
