# Olist 배송 지연이 리뷰 점수·재구매율에 미치는 영향 분석

## 프로젝트 개요
- **데이터**: Brazilian E-Commerce Public Dataset by Olist (Kaggle)
- **기간**: 2026.07.21 ~ 진행중
- **도구**: SQLite, Python(pandas, scipy), Tableau
- **목표**: 배송 지연이 (1) 리뷰 점수, (2) 재구매율에 미치는 영향을 통계적으로 검증하고, 비즈니스 액션으로 연결

## 핵심 인사이트

| 가설 | 결과 |
|---|---|
| 배송지연 → 리뷰점수 | 강한 부정적 영향 (Cramér's V=0.386, 4.29점 → 2.56점) |
| 배송지연 → 재구매율 | 통계적으로 유의하나 효과 미미 (Cramér's V=0.009, 3.03% → 2.49%) |
| 배송지연 → 리뷰점수 | 강한 부정적 영향 (Cramér's V=0.386, 4.29점 → 2.56점) |
| 배송지연 → 재구매율 | 통계적으로 유의하나 효과 미미 (Cramér's V=0.009, 3.03% → 2.49%) |
| 발송소요시간 → 배송지연 | 약한 상관관계 (Pearson 0.23) — 발송 속도만으로 지연 설명 부족 |
| 운송소요시간 → 배송지연 | 강한 상관관계 (Pearson 0.55) — 배송지연의 핵심 원인 |
| 판매자-고객 거리 → 배송지연 | 약한 음의 상관(-0.09), 역설적 — 예상소요일 보정으로 상쇄되는 것으로 확인 |

→ 고객은 배송 지연에 리뷰로는 강하게 반응하지만, 재구매 이탈로는 크게 이어지지 않는 비대칭적 반응 패턴이 확인됨. 리뷰 관리(응대·보상)는 시급한 과제인 반면, 재구매율 방어만을 목적으로 한 물류 투자 우선순위는 상대적으로 낮을 수 있음을 시사.

## 비즈니스 제안

이번 분석은 배송 지연이라는 단일 변수에서 출발해, 그 영향(리뷰·재구매)과 원인(발송/운송/거리)까지 함께 살펴보았다. 결과를 종합하면 다음과 같은 우선순위 재조정을 제안한다.

**1. 물류 투자의 목적을 "재구매 방어"가 아닌 "리뷰·평판 방어"로 재정의해야 한다.**  
배송 지연은 리뷰 점수에 강한 부정적 영향을 미치지만(Cramér's V=0.386), 재구매율에는 통계적으로 유의하나 실질적 영향은 미미하다(Cramér's V=0.009). 즉 지연 대응 투자의 1차 효과는 이탈 방지가 아니라 즉각적인 브랜드 신뢰도·CS 부담 완화로 봐야 한다.

**2. 지연의 핵심 원인은 판매자의 발송 속도가 아니라 운송 구간에 있다.**  
판매자 발송 소요시간(carrier_lag)은 최종 지연과 약한 상관관계(0.23)를 보인 반면, 택배사 인계 이후 운송 소요시간(transit_lag)은 훨씬 강한 상관관계(0.55)를 보였다. 판매자 온보딩 기준 강화보다 운송 파트너사 성과 관리에 우선순위를 두는 것이 더 효율적일 것으로 판단된다.

**3. 물류센터 입지(거리) 투자만으로는 지연 문제가 해결되지 않는다.**  
판매자-고객 거리는 최종 지연(mi_date)과 약한 음의 상관관계(-0.09)를 보였는데, 이는 거리가 지연을 줄여서가 아니라 Olist가 이미 거리에 비례해 예상 배송일을 넉넉하게 산정하고 있기 때문으로 확인되었다(거리-예상소요일 상관관계 0.52). 즉 거리 자체보다 운송의 변동성(신뢰성) 관리가 더 근본적인 과제다.

**4. 극단적 지연은 예측이 아닌 모니터링 대상이다.**  
운송이 100일 이상 걸린 극단 사례(35건)는 특정 판매자나 지역에 구조적으로 집중되지 않고 분산되어 있어, 사전 방지보다는 실시간 이상 감지·선제 대응 체계 구축이 더 실효성 있는 접근으로 판단된다.

**제안 요약**: 신규 물류센터 건설 같은 고정 인프라 투자보다, ① 운송 파트너사 성과 모니터링 체계 구축, ② 실시간 배송 이상 감지 시스템, ③ 지연 발생 고객 대상 선제적 리뷰 관리(사과·보상 프로세스)에 우선 투자할 것을 제안한다.

> 본 제안은 공개 데이터셋 기반의 학습용 분석 결과이며, 실제 물류 투자 의사결정에는 원가·계약 조건 등 추가 변수 검토가 필요하다.


## 분석 과정

1. **데이터 정제**: 배송완료(delivered) 주문 중 도착일 이상치(2017-09-19, 282건)를 발견 → 정상 배송일 대비 구매일 분포 비교로 데이터 오류임을 검증 후 제외
2. **리뷰 데이터 정제**: order_id당 리뷰가 최대 3건까지 중복되는 것을 발견 → 원인 규명(재작성 추정) 후 최신 답변 기준으로 1건만 남김
3. **가설 1 검증**: 카이제곱 검정 + Cramér's V로 유의성·효과크기·방향을 모두 확인
4. **가설 2 검증**: 첫 시도(모든 주문 중 하나라도 지연 여부로 정의)에서 결과 방향이 가설과 반대로 나옴 → 역인과관계(재구매 결정 이후 발생한 지연까지 원인에 포함됨) 문제로 원인 규명 → 고객별 **첫 주문** 기준으로 재정의하여 재검증
5. **가설 3 검증**: 배송 지연을 발송 구간(carrier_lag)과 운송 구간(transit_lag)으로 나눠 원인을 세분화. 운송 구간이 지연의 핵심 원인으로 확인됨. 극단값(35건)은 특정 판매자·지역에 집중되지 않아 개별 물류 이슈로 해석
6. **가설 4 검증**: 거리(distance_km)와 지연일수는 약한 음의 상관관계로 역설적 결과가 나옴 → 거리와 예상 배송 소요일(estimated_days)의 관계를 추가 분석해, Olist가 거리 비례로 예상 배송일을 넉넉하게 잡아주기 때문에 상대지표(mi_date)에서 상쇄되는 것임을 규명
